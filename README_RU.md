# Omni Flash Video Studio — Android APK project

Это проект исходников приложения на Kivy. Готовый APK не приложен: сборка Android требует SDK/NDK и Buildozer, который обычно запускают на Linux/macOS или Windows через WSL.

## Важно
- Перед использованием проверьте актуальное имя модели, доступность аккаунта и точную схему API в официальной документации: https://ai.google.dev/gemini-api/docs/video
- API может отклонить примерный endpoint/payload, если схема Interactions API изменится или модель недоступна. Этот проект — стартовый шаблон, не подтверждённая интеграция с закрытым Google Flow.
- Видео сохраняется в приватной папке приложения. Для публикационной версии лучше добавить системный Android Save As/MediaStore.
- Не делитесь API-ключом и не встраивайте личный ключ в APK, который распространяете.

## Сборка APK через Linux / WSL
1. Распакуйте архив в Linux.
2. Установите Buildozer и системные зависимости по инструкции: https://buildozer.readthedocs.io/
3. В каталоге проекта запустите:
   ```bash
   buildozer android debug
   ```
4. После сборки APK будет в `bin/`.

Для Windows используйте WSL2 с Ubuntu; на одном Android-телефоне собрать полноценный APK обычно неудобно. Можно собрать проект на компьютере или CI-сервисе, а затем перенести APK на телефон.
